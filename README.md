## 📌 Highlighted Work

### 🔬 SEM Image Denoising (NanoVision, Kama-Tech)
Turning fast, noisy electron-microscope scans into clean images with deep learning.
Compared NAFNet, Restormer and IDF on real scan pairs, tuned with Optuna, and found that the noise
runs along the scan rows. A row-aware self-supervised method (Structured Noise2Void) reached
**86% of the supervised gain without any clean training images**.

### 🤖 [AI Documentation RAG Agent](https://github.com/dassikelerman/AI-documentation-rag-agent)
Agentic RAG system in Python and LlamaIndex: a routing agent combines semantic and structured
retrieval (Pinecone) to answer questions over engineering documentation, with a Gradio interface.

### ♟️ [KungFu Chess](https://github.com/dassikelerman/KFChess)
Real-time chess where moves resolve after a delay. Multiplayer over a WebSocket server, with
matchmaking, private rooms, reconnection and ELO ratings.

### 🌦 [MCP with Playwright](https://github.com/dassikelerman/MCP-with-Playwright---Project)
MCP-based automation in Python and Playwright that collects live weather data and summarizes it with an LLM.

### 🎫 [HelpDesk](https://github.com/dassikelerman/HelpDesk-React)
